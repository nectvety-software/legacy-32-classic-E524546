# Hello App — C++ HOST sample

Dùng `../../tools/qstudio.py simulate --demo hello --scenario playing -o screenshot.png` từ thư mục root bộ kit. Ví dụ app và game dùng chung Runtime/Platform; OK tăng biến đếm, OPTION đổi màu, BACK reset. `MENU`/`SELECT long` luôn được host chuyển thành reserved system events.

Đây là nguồn minh họa API C++ trên máy tính, **không phải** app `.qeapp` cài được trên firmware.
