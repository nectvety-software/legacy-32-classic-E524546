# QEAPP-Studio — Default Project Agent Kit

Bộ prompt/skills **chuyên đề** dành cho AI Agent triển khai cấu trúc project mặc định của QEAPP-Studio.

**Không chép đè `PROMPT.md` và `SKILLS.md` ở gốc repo**: chúng hiện chứa quy tắc phối hợp nhiều Agent. Hãy giải nén 2 tệp vào:

```
QEAPP-Studio/docs/agents/default-project/PROMPT.md
QEAPP-Studio/docs/agents/default-project/SKILLS.md
```

Sau đó giao nhiệm vụ cho Agent bằng lệnh:

> Đọc AGENTS.md, PROMPT.md, SKILLS.md ở gốc. Triển khai yêu cầu trong docs/agents/default-project/PROMPT.md và quy trình docs/agents/default-project/SKILLS.md. Chỉ sửa QEAPP-Studio, chạy test, báo cáo PASS/FAIL/SKIPPED/NOT_RUN, không sửa VQEAF-OS hoặc ghi đè project hiện có.

Bản này là **tài liệu triển khai**; chưa thay đổi QEAPP-Studio và chưa commit GitHub.
