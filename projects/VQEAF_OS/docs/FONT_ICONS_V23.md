# VQEAF OS v2.3 — Typography and icon implementation guide

- **ASCII fast path:** use `ui.textBold(x,y,text, UiTypography::CAPTION/BODY/TITLE, fg,bg)` rather than calling TFT_eSPI directly from new screen code. Shared widgets already do this for their labels and headings. `UiTypography.h` defines stable glyph roles.
- **Vietnamese:** pass valid UTF-8 NFC text. The generated `UiVietnameseFont.h` maps a fixed subset of 229 Vietnamese precomposed and printable-ASCII Unicode points into two raster sizes without TTF loading. The role switch is the same as ASCII. Avoid long arbitrary HTML text through this small UI font path; the browser has its own document renderer.
- **Clipping:** call `ui.fitTextPixels(text, role, maxWidth)` before centering; this never truncates in the middle of a multibyte UTF-8 codepoint. Font metrics come from real renderer for accented strings rather than `String.length()` bytes.
- **Glyph provenance:** this package includes **generated bitmap arrays**, not `.ttf` / `.otf`. Shapes are derived from the freely redistributable DejaVu family; the required license and credit notice is in `third_party/DejaVu_Glyph_Attribution.txt`. To regenerate on a licensed development machine with Pillow and the installed family: `python tools/generate_vietnamese_glyphs.py`. No runtime Python dependency exists on ESP32.
- **Icon policy:** call `ui.drawIcon(x,y,"Wi"/"BLE"/"Mus"/"Dir"/"Pic"/"Web"/"Term"/"Rec"/"Set"/"Th"/"App"/"Col", tileBg)`. Do not draw additional legacy 24px art. All icons are procedural vector/pixel art with the same **36×36** canvas and no external license-sensitive assets; `UiIconCatalog.h` normalizes aliases and provides grid ordering.
- **Safe migration:** external .qeapp icons are signed payload assets and are intentionally not altered. `Explorer` is a separate Retro-inspired browsing mode with smaller two-letter badges; migrate separately if visual matching is requested for that optional mode.
- **Limit:** legacy app-specific hand-positioned text and rare combining diacritics are not fully covered by this pass. `UiVietnameseFont` does not implement shaping or normalization of decomposed combining sequences at runtime.
