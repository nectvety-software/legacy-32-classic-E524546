Symbian S3 OS v1.0.1 - Centered S60 Statusbar Test Report
===========================================================

Target contract
---------------
- ESP32-S3-WROOM-1 N16R8
- ST7789 portrait 240x320
- TFT_ROTATION=0
- Status indicators: WiFi + battery only; no SIM/cellular icon

Title/statusbar changes
-----------------------
- 27 px S60 top bar retained.
- LCD width is split into three equal 80 px zones:
    0..79   application title
    80..159 centered clock
    160..239 WiFi + battery status
- Clock X is calculated from complete screen width: (240 - textWidth(time)) / 2.
- WiFi and battery each occupy an equal 40 px slot inside the right status zone.
- Title text is clipped by rendered pixel width so it cannot overlap the clock.
- Active Standby/Home uses the same title/status geometry.
- RSSI changes repaint only the right 80 px status region; full-screen redraw is not used.
