Symbian S3 OS v1.4.0 - QEAPP/1 App Installer
===========================================
Target: ESP32-S3 WROOM N16R8 / ST7789 portrait 240x320
Date: 2026-09-24

WHAT WAS BUILT
--------------
- Binary QEAPP/1 format: length-checked bounded manifest (<=2048 B),
  optional RGB565 32x32 icon (2048 B), optional payload (<=256 KiB).
- SHA-256 validation of all sections before install and again while copying.
- Atomic-style staging directory -> installed directory rename.
- App installer Inbox/Installed UI: name/version/type, verified icon detail,
  Install/Uninstall with confirmation and error feedback.
- Installed apps registered in Applications with icons, opening animation;
  `web` apps launch Qeafbrowser, `text` apps launch the existing Text Viewer.
- File Manager and browser download handoff for .qeapp packages.
- On-boot installed catalog scan capped at 12 entries; catalog full check.
- No native executable loading. See docs/QEAPP_V14.md.

LIMITS AND IMPORTANT WARNINGS
-----------------------------
- Host Arduino/ESP32 API mocks are not the real Espressif toolchain.
- PlatformIO target ESP32-S3 build and physical display/SD testing were NOT
  performed in this environment, because `pio` is not installed here.
- No hardware screenshot is claimed. The included image is a geometry mock.
- SHA-256 proves package bytes match the header, but does not authenticate
  the creator. There is no trusted publisher signature system yet.
- .qeapp v1 contains declarative HTTPS launcher or text only. It does NOT
  install/execute VXP, ZIP, ELF, JavaScript or third-party native binaries.
- SD write interruption can leave .stage-<id> directories; inspect and clean
  manually before retry. Runtime SD failure needs board testing.

BUILD/FLASH ON THE BOARD
------------------------
cd SymbianS3_OS
pio run -t clean
pio run
pio run -t upload
pio device monitor -b 115200
