Symbian S3 OS v1.7.0 — Saved WiFi Auto Connect
Target: ESP32-S3 N16R8 / ST7789 portrait 240x320

Changes
-------
- Asynchronous startup scan across all saved SSIDs; strongest measured RSSI first.
- Last successful SSID only breaks equal-signal ties.
- Per-network 12s association deadline; fallback to next saved AP.
- Recover from link drop after 5s; back off 30/60/120s on exhausted scans.
- Safe Mode, Settings and explicit user Disconnect disable automatic selection.
- S60 Idle shows scanning / joining SSID / SSID RSSI / retry countdown.
- Status line partial redraw (205x15) + compact 45px WiFi/battery corner.
- Foreground titlebar WiFi status updated from cached chrome without a fullscreen redraw.
- Shell direct WiFi commands cannot race the background selector.
- No additional full-screen framebuffer, no new FreeRTOS thread.

Limits
------
All RF scenarios were simulated with a fake Arduino WiFi API. GNU++11
compilation/link used stubbed Arduino/TFT interfaces. Real PlatformIO
espressif32 build and tests with actual WiFi access points were NOT run
because PlatformIO ESP32 toolchain is unavailable in this environment.

Image previews are generated UI illustrations, not photos/LCD captures.
