PlatformIO note
---------------
PlatformIO/ESP32 target toolchain is not installed in this execution environment,
so `pio run` and real ST7789 hardware timing were not executed here. Run a clean
PlatformIO build on the target PC before flashing:

  pio run -t clean
  pio run
  pio run -t upload
  pio device monitor -b 115200
