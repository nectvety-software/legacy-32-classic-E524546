POCHITA Retro-Go ROM folders
============================

Copy only game dumps that you are legally allowed to use:

  /roms/nes    Nintendo Entertainment System (.nes)
  /roms/gb     Game Boy (.gb)
  /roms/gbc    Game Boy Color (.gbc)
  /roms/sms    Master System (.sms)
  /roms/gg     Game Gear (.gg)
  /roms/md     Mega Drive / Genesis (.md, .gen, .bin)

OpenRhynn.nes is the mapper-0 NES homebrew edition. Copy it to /roms/nes and
launch it with the Retro-Go NES core.

OpenRhynn.bin is a POCHITA native package, not a Mega Drive ROM. Its magic
header is detected before the normal .bin file type handling.
